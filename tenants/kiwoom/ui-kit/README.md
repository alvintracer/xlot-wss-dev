# Kiwoom UI authority

The original screenshots in this directory and the extracted guide are the visual authority for Kiwoom-visible WSS screens.

Read in this order:

1. `kiwoom-wallet-ui-guide/AGENT_IMPLEMENTATION_BRIEF.md`
2. `kiwoom-wallet-ui-guide/UI_DESIGN_GUIDE.md`
3. `kiwoom-wallet-ui-guide/design/tokens.json`
4. `kiwoom-wallet-ui-guide/design/measurements.json`
5. `kiwoom-wallet-ui-guide/src/wallet-ui-contract.ts`
6. `kiwoom-wallet-ui-guide/qa/ACCEPTANCE_CHECKLIST.md`
7. `UI_REFERENCE_CATALOG.md`에서 구현 주제별 원본 이미지 선택

Do not edit or replace the supplied screenshots. Do not describe the guide as an official Kiwoom design system; it is screenshot-derived. The phone preview and embedded wallet follow this authority, while WSS Studio and outer simulator controls follow `@took-wss/ops-ui`.

New screenshot batches arrive under `new/`. Read `new/README.md` for the current asset-tab inventory and `../../../docs/UI_REFERENCE_INGEST.md` for the lightweight naming/privacy workflow. Files in `new/` are intake evidence; the extracted guide remains the implementation authority until approved references are promoted. Root source filenames and masked R01–R19 filenames are indexed in `UI_REFERENCE_CATALOG.md` so typography, detail density, sheets, carousel, keypad boundary, and loading/empty states can be traced without reopening every image.
