# UI 검수 체크리스트

자동 테스트 결과는 `test-results.json`을 참고한다. 자동 테스트 통과는 기능 예시의 렌더링·가로 폭·선택된 상태 흐름에 대한 결과이며 원본 시각 동일성/실서비스 안전성을 보증하지 않는다.

## A. 입력 자료 / 브랜드

- [ ] 실제 키움 앱 폰트와 weight를 연결했다. 폰트 파일은 이 배포물에 포함하지 않는다.
- [ ] 공식 아이콘·로고·일러스트로 대체했다. 검수용 크롭·임시 SVG·티커 글자를 남기지 않았다.
- [ ] 촬영 키패드 R19를 정밀 색상/치수 근거로 쓰지 않았다.
- [ ] 개인정보가 포함된 원본 이미지를 개발 샘플·외부 전달 파일에 복사하지 않았다.

## B. 레이아웃 / 일치

- [ ] 648→360은 비교 좌표라는 점을 구분하고 실제 단말 viewport를 확인했다.
- [ ] 루트 회색 / 상세 흰색 셸이 분리돼 있다.
- [ ] 큰 카드 외부 12, 내부 가로 20, 세로 24–28, radius 24를 확인했다.
- [ ] 헤더·버튼·시트·카드·밑줄의 경계 위치를 R10/R15/R16과 대조했다.
- [ ] 일반 CTA / 거래 CTA / 입력값 / placeholder / 라벨의 글자 크기를 구분했다.
- [ ] 데이터가 길어져도 금액·단위·네트워크·수신처·오류를 숨기지 않는다.
- [ ] 320/360/390/430 너비에서 가로 overflow가 없다.
- [ ] 고정 CTA가 본문 마지막 행을 가리지 않는다. 키보드 표시 중 입력 필드를 확인했다.
- [ ] 상태 바·시스템 버튼을 제품 코드에서 가짜로 그리지 않는다.
- [ ] safe-area와 호스트 padding을 중복 적용하지 않는다.
- [ ] 기존 루트 탭과 SDK의 탭이 중복되지 않는다.

## C. 사용자 흐름 / 데이터

- [ ] 원화 입력 후 고정할 토큰 수량·견적 만료 시점을 명확히 한다.
- [ ] chain ID + asset ID를 사용하고 동일 심볼의 다른 네트워크를 구분한다.
- [ ] tag/memo가 필요한 경우 받기·보내기·최종 확인 모두에서 제공한다.
- [ ] 실제 수신 주소로 QR을 생성하고 읽기 검증했다. demo QR/주소가 남아 있지 않다.
- [ ] 사용 가능 잔액·최대 송금액·수수료 계산은 실제 코어 결과를 사용한다.
- [ ] 최종 확인에 주소·체인·수량·수수료·차감 방식·부담주체가 있다.
- [ ] 입력 변경 시 정책/견적/인증 승인을 무효화한다.
- [ ] 견적 만료 / 정책 조회 실패 / 제한 / 추가 확인 상태를 테스트했다.
- [ ] 호스트 인증과 코어 서명이 분리된 계약으로 처리된다.
- [ ] 승인 중 중복 실행이 방지되고 서버/코어에서 멱등성을 재검증한다.
- [ ] 전송 요청, 네트워크 확정 대기, 확정 완료, 실패, 결과 불명 상태를 구분한다.
- [ ] timeout 후 무조건 재송금하지 않는다.
- [ ] 복구 방식·수탁 모드·지원 네트워크는 프로파일/capability에 따른다.
- [ ] 원화 시세 미갱신을 실제 잔액 0원으로 표시하지 않는다.

## D. 접근성 / 안전

- [ ] 시트 role/name/modal/focus trap/닫기 후 focus 복귀를 확인했다.
- [ ] 화면 색상 외에 문구와 아이콘으로 상태를 구분한다.
- [ ] 작은 아이콘의 터치 영역과 native 플랫폼 요구를 확인했다.
- [ ] 큰 글자·스크린리더·키보드 탐색·reduce motion을 확인했다.
- [ ] 비밀키·시드·PIN·개인정보가 UI 로그/분석 이벤트에 포함되지 않는다.
- [ ] 기존 보안 입력/인증 SDK를 재사용한다. 촬영 키패드 모양만 복제하지 않는다.
- [ ] KYT 결과를 “안전 보장”으로 표현하지 않는다.
- [ ] 신규 기능은 “지갑 확장”으로, 미확인 정책은 미확인으로 표시한다.

## 이번 패키지에서 실행한 검수 범위

14개 화면 렌더링, 대표 6개 지갑 화면 × 4가지 너비의 embedded 가로 폭, 수신처 입력→금액→정책 제한→견적 만료→승인 모달→확정 대기 예시, Escape로 모달 닫기, JavaScript 오류 수집을 점검했다. 원본 폰트·정식 에셋·실제 호스트 앱·보안 SDK·온체인 통합·스크린리더 실기기 검수는 수행 범위에 포함되지 않는다.

브라우저 환경의 URL 접근 제한 때문에 자동 점검은 HTML을 브라우저 문서에 직접 주입해 수행했다. 파일에는 외부 폰트/CDN/네트워크 의존성을 넣지 않았다. 사용자의 브라우저에서 로컬 파일 열기 또는 clipboard 권한이 제한되는 경우는 별도 환경 제약이다.
