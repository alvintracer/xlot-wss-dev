# took! → WSS tenant parity audit (2026-10-02)

This is a dated snapshot. For the current phone escrow asset matrix and limits,
see `docs/PHONE_ESCROW_EXECUTION.md`.

Scope: Kiwoom and JB share the same WSS wallet runtime and BFF. The comparison source is the private `alvintracer/xlot` repository (`traverse-wallet`, took!) at its 2026-10-02 `main` snapshot, read for evidence only. A source implementation does not prove that every provider is currently enabled in production. The bank apps at `/kiwoom/app` and `/jb/app` are reference-host PWA previews, not integrated native bank releases.

## Implemented or partially implemented

- WSS has real SAR wallet creation/import, multiple wallet slots, nine-chain balance/address reads, address receive QR, direct sends for native and allowlisted stablecoin assets, KYT gate, phone escrow sender preparation, and same-chain EVM exchange quote/signing. See `docs/ROADMAP.md` for the gates and limits.
- Both tenant manifests select the same `gas-sponsorship` and `send-receive` modules. Canonical USDC address sends on Ethereum, Polygon, Arbitrum, and Base use Took Pay's `took-pay-transfer-relay` and Router V2 if the provider is configured and onchain fee state is readable. The sender signs authorization and Permit inside the host SAR key core; the server receives signatures and never receives mnemonic/private key material. The router fee is charged in USDC; the relayer pays native network gas. Direct transfer fallback is prepared only as a disclosed, separate route when the relay quote is unavailable. Relay submissions have a durable WSS claim, status reconciliation, and customer activity/history. A Base mainnet fork verified the deployed router with a zero-ETH customer wallet and exact recipient/fee amounts; no funded mainnet transfer was made during this audit. Canonical Solana USDC now has a server-only payer cosign route, strict instruction validation, and a daily sponsorship quota; live cosigning was checked without broadcast.
- A recipient claim page, SMS OTP gate, recipient risk check, matching contract signer relay, and sender refund path exist for the phone escrow lifecycle. A Base mainnet fork verified real USDC deposit and expiry refund. The production sender pilot is limited to Base USDC and 2 USDC per transfer; funded claim remains unverified.
- The reference host offers camera/image QR scanning and the browser Contact Picker bridge when supported. Scanned addresses are checked against the selected chain before transfer preparation. Same-chain EVM exchange has a configured 0x v2 provider; a read-only Base firm quote returned HTTP 200 with liquidity and a transaction. Token approval settles separately, followed by a fresh quote and swap signature; the Base fork verified approval confirmation. Funded swap execution remains unverified.
- JB's Paperlogy Bold is limited to large page headings; base text uses the Korean system/Noto stack.
