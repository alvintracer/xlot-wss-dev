# 금융사별 앱 PIN 결정 · 2026-10-12

## 선택

키움·JB·나무는 **각 금융사 앱의 고객별 PIN 하나**를 사용한다. 서로 다른 금융사나 고객은 같은 기기에서도 PIN 검증 기록을 공유하지 않는다. PIN은 숫자 6자리이고, 이 기기에서만 사용한다.

설정의 `앱 비밀번호 설정`에서 PIN을 두 번 입력해 만들 수 있다. 기존 월렛을 그대로 사용하는 고객도 새 월렛을 만들 필요가 없다.

## 월렛 키와 복구

자가복구 월렛의 마스터 비밀번호와 SAR 복구 조건은 계속 월렛마다 독립적이다. 앱 PIN은 각 월렛의 로컬 보관함을 여는 수단이며 서버에 전송하지 않는다. 로컬 월렛 자료는 각각 별도 기기 키와 암호화 봉투로 보관한다. Thirdweb 월렛의 서명은 해당 계정 인증을 사용하며 앱 PIN으로 대신하지 않는다.

기존 기기의 월렛마다 PIN이 다르면 첫 서명 때 앱 PIN을 확인한 뒤, 해당 월렛의 **이전 PIN을 한 번 더 입력**해 로컬 봉투의 PIN 부분만 다시 암호화한다. 마스터 비밀번호 봉투와 SAR 복구 정보는 변경하지 않는다. 다른 월렛의 이전 PIN을 자동으로 추측하거나 서버에서 받아오지 않는다.

## 생체 인증

나무 Android 앱에서는 사용자가 앱 PIN을 직접 확인한 뒤 생체 인증을 켤 수 있다. 생체 인증은 기기 보안 저장소의 앱 PIN을 사용할 때마다 OS 인증을 요구한다. 생체 정보 자체와 PIN은 WSS 서버에 보내지 않는다. 생체 인증이 실패하거나 기기 설정이 달라지면 앱 PIN을 직접 입력할 수 있다.

키움·JB PWA의 설정 화면은 같은 구조를 제공하지만, 안전한 기기 저장소가 연결되지 않은 웹 환경에서는 생체 스위치를 활성화하지 않는다. 두 금융사의 네이티브 앱을 빌드할 때 동일한 기기 보안 저장 경로를 연결한다.

## 검증 기준

- 세션 토큰이 갱신되어도 같은 금융사·고객의 앱 PIN 범위가 유지된다.
- 다른 금융사·고객의 앱 PIN 검증 기록은 서로 다른 범위에 저장된다.
- 기존 월렛 PIN 이전 후 이전 PIN은 열리지 않고 새 앱 PIN과 마스터 비밀번호는 각각 열리며, 마스터 봉투는 그대로다.
- 앱 PIN이나 생체 인증을 꺼도 SAR 복구 조건과 서버 지갑 주소는 달라지지 않는다.
