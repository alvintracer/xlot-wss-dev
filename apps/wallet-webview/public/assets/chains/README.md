# Chain icons

These files are customer-facing network marks. Asset/token selection continues
to use the separate `assets/coins` catalog.

- Ethereum, Polygon, BNB Chain, Solana, Bitcoin, TRON, and XRP were copied from
  the existing took application icon catalog on 2026-09-28.
- Arbitrum and Base were sourced from the Trust Wallet assets repository on
  2026-09-28 and checked against each network's official brand guidance.

Keep filenames aligned with the canonical WSS `chainId` values. Do not replace
a chain mark with the selected token's mark in a network-selection control.
