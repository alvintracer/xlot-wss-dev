# WSS coin icon catalog

Customer-facing asset icons are served locally from this directory. Runtime UI
uses the vetted `coin:<lowercase-symbol>` identifier and never hotlinks a market
data site.

## Sources

- `bnb`, `btc`, `dai`, `eth`, `eurc`, `jpyc`, `pol`, `pyusd`, `rlusd`, `sol`,
  `trx`, `usdc`, `usdt`, `xrp`, and `xsgd` were copied from the existing took
  wallet asset catalog on 2026-09-28.
- `fdusd` (CMC ID 26081), `gusd` (3306), `usdg` (33793), `usdp` (3330), `usds`
  (33039), and `xusd` (32372) were downloaded from CoinMarketCap's static
  128x128 coin image endpoint on 2026-09-28.

Logos and names remain trademarks of their respective owners. Revalidate an
icon when an issuer rebrands, migrates a token, or changes its canonical mark.
